Featuring both interface powered by Charmbracelet, which is recommend in the guideline yayyy
## Features
- **SSH Terminal:** Connect via SSH for an interactive terminal guestbook experience styled with `bubbletea` and `lipgloss`.
- **Storage:** Automatically saves messages with to a local text file without self checking needed!!

### Connecting via SSH
Open a separate terminal window and run: ssh localhost -p 2222

### Accessing the Web Page
Open your browser and navigate to: http://localhost:8080
