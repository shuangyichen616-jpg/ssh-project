

A guestbook application built in Go using VS. Featuring both an interactive terminal interface powered by Charmbracelet.
## Features
- **SSH Terminal Interface:** Connect via SSH for an interactive terminal guestbook experience styled with `bubbletea` and `lipgloss`.
- **Thread-Safe Storage:** Automatically saves messages with timestamps to a local text file.

### Prerequisites
- Go (version 1.18 or higher)

### Connecting via SSH
Open a separate terminal window and run: ssh localhost -p 2222

### Accessing the Web Page
Open your browser and navigate to: http://localhost:8080
